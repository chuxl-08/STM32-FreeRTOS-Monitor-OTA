# 硬件连接与引脚分配

## 开发板与电平约束

项目使用 STM32F103ZE 开发板，MCU IO 电平为 3.3 V。

开发板、模块数据手册和接线参考资料整理在 [硬件参考资料压缩包](../reference.zip)。

## 外设连接总表

| 模块 | 信号 | STM32 引脚 | 外设功能 | 说明 |
| --- | --- | --- | --- | --- |
| 调试串口 | TX | PA9 | USART1_TX | 输出运行日志。 |
| 调试串口 | RX | PA10 | USART1_RX | 预留串口接收。 |
| OLED SSD1306 | SCL | PB6 | I2C1_SCL | 与 AMG8833 共用 I2C1。 |
| OLED SSD1306 | SDA | PB7 | I2C1_SDA | 7 位地址通常为 0x3C。 |
| AMG8833 | SCL | PB6 | I2C1_SCL | 与 OLED 共用 I2C1。 |
| AMG8833 | SDA | PB7 | I2C1_SDA | 当前按 7 位地址 0x69 使用。 |
| DHT11 | DATA | PC2 | GPIO | 单总线数据线。 |
| 光敏模块 | AO | PC0 | ADC1_IN10 | 读取模拟光照值。 |
| HC-SR04 | TRIG | PC3 | GPIO 输出 | 触发超声波测距。 |
| HC-SR04 | ECHO | PA1 | TIM2_CH2 | 输入捕获 Echo 高电平时间。 |
| 舵机 | PWM | PB8 | TIM4_CH3 | 50 Hz PWM 控制角度。 |
| ESP01 | MCU TX / 模块 RXD | PB10 | USART3_TX | 发送 AT 指令。 |
| ESP01 | MCU RX / 模块 TXD | PB11 | USART3_RX | 接收 AT 响应。 |
| 旋转编码器 | A / CLK | PC6 | TIM3_CH1 | TIM3 编码器模式，完全重映射。 |
| 旋转编码器 | B / DT | PC7 | TIM3_CH2 | TIM3 编码器模式，完全重映射。 |
| 旋转编码器 | SW | PC4 | EXTI4 / GPIO | 编码器按键输入。 |
| 板载 LED | D3 | PB5 | GPIO 输出 | 板级状态测试。 |
| 板载 LED | D4 | PB0 | GPIO 输出 | 板级状态测试。 |
| 板载 LED | D5 | PB1 | GPIO 输出 | 板级状态测试。 |

## 外设资源占用

| 外设资源 | 引脚 | 使用者 | 说明 |
| --- | --- | --- | --- |
| USART1 | PA9 / PA10 | 调试日志 | 当前主要用于 USART1 日志输出。 |
| USART3 | PB10 / PB11 | ESP01 | AT 指令发送与响应接收。 |
| I2C1 | PB6 / PB7 | OLED、AMG8833 | 共享总线，通过任务层 I2C mutex 保护。 |
| ADC1 | PC0 / ADC1_IN10 | 光敏模块 | 读取 AO 模拟输出。 |
| TIM2 | PA1 / TIM2_CH2 | HC-SR04 Echo | 输入捕获高电平宽度。 |
| TIM3 | PC6 / PC7 | 旋转编码器 | 编码器模式，需要完全重映射。 |
| TIM4 | PB8 / TIM4_CH3 | 舵机 | 20 ms 周期 PWM。 |
| EXTI4 | PC4 | 编码器按键 | 按键事件输入。 |

## I2C 设备地址

| 设备 | 7 位地址 | 说明 |
| --- | ---: | --- |
| OLED SSD1306 | 0x3C | OLED 显示模块。 |
| AMG8833 | 0x69 | 8x8 热阵列传感器。 |
| AT24C02 | 0x50 | 开发板板载 EEPROM，和外接 I2C 设备共总线。 |

## 电源与接线注意事项

- STM32、OLED、AMG8833、DHT11、光敏模块均按 3.3 V 逻辑连接。
- 舵机、 ESP01、旋转编码器使用外部 5 V 电源，并与 STM32 共地。
